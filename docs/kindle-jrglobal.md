# Jovian Research 四大工具数据模块

`tools/jrglobal_radar.py` 把 [jrglobal.xyz/tools](https://jrglobal.xyz/tools/) 的四个工具接进
同花顺行情面板：**聪明钱雷达、AI 数据智库、组合实验室、宏观看板**。数据同时进入
`site/stocks.json`、`stocks.html`、`stocks.epub` 和 `stocks.txt`；网页另有股票/经理即时反查框。

> 当前内置快照日期为 **2026-11-20**，持仓报告期为 **Q3 2026**。这里的“实盘”指已经落盘、
> 可复核日期与字段的真实工具快照，不等于逐笔实时行情。A 股当日行情仍来自同花顺快照，
> 两种数据有各自的数据时间，不能把面板构建时间当成持仓披露日。

## 1. 新增模块与接线

| 位置 | 新增内容 |
| --- | --- |
| `tools/jrglobal_radar.py` | 四工具快照、覆盖口径、股票反查索引、当日盘面交叉核验、纯文本/EPUB 渲染 |
| `tools/build_stocks.py` | `radar_section()` 接入清单；网页、EPUB、纯文本都输出四工具数据 |
| `site/stocks.json` | 新增 `radar`：`coverage`、`tool_inventory`、持仓、AI 指标、组合、宏观目录、反查索引与盘面命中 |
| `site/stocks.html` | 四工具总表、A/美股持仓、股票/经理搜索、产业链数据、组合收益及宏观目录 |
| `site/stocks.epub` | crengine 兼容的纯表格版本，不使用 grid/flex/SVG |
| `site/stocks.txt` | 46 列折行的 Kindle 纯文本版本；周末精简版只留核心共识 |
| `tests/test_stocks.py` | 反查、盘面命中、四工具顺序、宏观口径及三端渲染回归测试 |

核心流程：

```text
同花顺当日快照 ─┐
涨停池/涨幅榜 ──┼─ cross_verify_panel() ─ radar ─ JSON / HTML / EPUB / TXT
四工具基准快照 ─┘                         └─ 盘面命中 + 产业链交叉核验
```

## 3. 当日盘面如何联动

`cross_verify_panel()` 做两层只读匹配：

1. 从全 A 涨幅榜和涨停池取候选股票，用代码优先、简称兜底反查聪明钱持仓；
2. 把涨停题材与半导体出口、WSTS 销售、台湾算力链营收、OCPI、企业 AI 采用率并列显示。

输出字段：

| 字段 | 含义 |
| --- | --- |
| `radar.panel_matches` | 当日涨幅榜/涨停池命中的聪明钱重仓股 |
| `radar.stock_index` | 网页端本地反查索引 |
| `radar.supply_chain_verify` | 产业链硬数据交叉说明 |
| `radar.tool_inventory` | 四工具本次实际落盘口径与数量 |
| `radar.coverage` | 源站全量覆盖规模 |
| `radar.macro_data.scope` | 明确宏观段是目录口径还是单点读数 |

匹配不改变原始行情，也不会自动推荐股票。没有命中就保持空数组，不硬凑结果。

## 5. 数据边界

- 四工具快照、同花顺 A 股行情和腾讯港股行情有不同数据时间；以各段标注为准。
- 13F、公募季报天然滞后，不是基金经理当前仓位；季度动作不能当作今日成交。
- `本地明细` 是为了 Kindle 排版选出的代表样本；`coverage` 才是源站全量规模。
- 宏观看板目前只有目录覆盖，不输出无来源日期的单点数值。
- 组合收益来自工具快照，不代表未来表现；所有内容仅供信息展示，不构成投资建议。
